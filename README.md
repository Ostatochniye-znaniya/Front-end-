# Frontend для проекта "Остаточные знания"

## Dev запуск

-  Запуск программы на 3000 порте


```bash
make dev-up
```

- Запуск программы на 3000 порте в автономном режиме


```bash
make dev-up-d
```

- Завершение программы


```bash
make dev-down
```
