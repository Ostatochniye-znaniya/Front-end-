## Локальный запуск

Перейдите в папку `frontend` и выполните:

```bash
npm install
npm run dev
```

Приложение будет запущено в режиме разработки. По умолчанию Next.js использует порт `3000`.

## Проверка и сборка

Команды выполняются из папки `frontend`.

- Проверка кода: `npm run lint`
- Сборка приложения: `npm run build`
- Запуск собранного приложения: `npm run start`

Перед запуском через `npm run start` необходимо выполнить сборку.

## Запуск через Docker

Команды выполняются из корня репозитория.

### Разработка

- Запуск с выводом логов: `make dev-up`
- Запуск в фоновом режиме: `make dev-up-d`
- Остановка: `make dev-down`

### Конфигурация prod

- Запуск с выводом логов: `make prod-up`
- Запуск в фоновом режиме: `make prod-up-d`
- Остановка: `make prod-down`

Команды используют Docker Compose-конфигурации, указанные в корневом `Makefile`.
